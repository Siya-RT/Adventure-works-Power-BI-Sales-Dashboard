# Adventure-works-Power-BI-Sales-Dashboard
Interactive Power BI dashboard for Adventure Works sales, customer, product, profit, return, and regional analysis.

The project transforms business data into an interactive analytical report that helps users monitor key performance indicators, identify trends, compare actual performance with targets, and explore customer and product-level insights.

## 🎯 Project Objective

The objective of this project is to create an interactive and visually engaging Power BI dashboard that provides a comprehensive view of business performance.

The dashboard enables users to:

- Monitor sales and order performance
- Track revenue and profit trends
- Analyze product and category performance
- Understand customer purchasing behavior
- Monitor product returns and return rates
- Compare actual performance against targets
- Analyze business performance across regions
- Identify top-performing customers and products

---

## 🛠️ Tools & Technologies

- **Power BI Desktop** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures, KPIs, and business calculations
- **AdventureWorks Dataset** – Source business data
- **GitHub** – Project documentation and version control
